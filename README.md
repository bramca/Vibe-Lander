# Vibe Lander
![vibe lander game](./img/vibe-lander.png)
A `javascript` / `html` version of the 1979 Atari game [Lunar Lander](https://en.wikipedia.org/wiki/Lunar_Lander_%281979_video_game%29)<br>

😎 Completely vibe coded! 🔥

# How to run
You can run this game by opening the [index.html](./index.html) in your browser or you can run a simple http server in the root folder of this repo e.g. (in python) `python -m http.server`

# Controls
`arrow up` hold to thrust upward.<br>
`arrow left/right` hold to thrust the ship left or right.<br>
`r` when you crash, press this key to restart the game.<br>
`n` when you land, press this key to move to the next level.
